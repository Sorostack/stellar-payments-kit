# Glossary

- **XLM** — Stellar lumen, native asset
- **Soroban** — Stellar smart contract platform
- **SEP** — Stellar Ecosystem Proposal
- **Keypair** — Public/secret key pair for Stellar accounts
- **Horizon** — Stellar network API server
- **Claimable Balance** — Balance that can be claimed by a designated account
- **Liquidity Pool** — Automated market maker pool
- **Anchor** — Trusted issuer that bridges Stellar and traditional finance
